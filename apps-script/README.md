# 一周日常表 · Google Apps Script 版本

与网页版功能一致（拖拽框选建日程、可编辑标题与日期跨度、与会人员、显示时段切换、中英文、打印），
**数据保存在 Google Sheet**，并新增「导出到 Google Sheet」能力。

## 文件

| 文件 | 用途 | 粘贴到 Apps Script 的位置 |
| --- | --- | --- |
| `Code.gs` | 后端：读写表格、导出 | 默认的 `Code.gs` 文件 |
| `Index.html` | 前端界面（HTML 文件名必须是 `Index`） | 新建的 HTML 文件，命名为 `Index` |
| `appsscript.json` | 清单：时区 + Web App 权限（可选） | 项目设置中开启显示后编辑 |

## 部署步骤

1. 打开 <https://script.google.com/home> → 左上角 **新建项目**。
2. 把项目重命名为「一周日常表」。
3. 打开 `Code.gs`，全选删除原内容，粘贴本项目 `Code.gs` 的全部内容，保存（⌘S）。
4. 左侧 **文件 → ＋ → HTML**，文件名填 **`Index`**（不要带 `.html`），粘贴 `Index.html` 的全部内容，保存。
5. 可选但推荐：**项目设置 → 勾选「在编辑器中显示 appsscript.json 清单文件」**，回到编辑器点开
   `appsscript.json` 并粘贴本项目内容（设定 `Asia/Shanghai` 时区与 Web App 权限）。
   若跳过这步，请在 **项目设置 → 时区** 手动选择 `(GMT+08:00) 上海`，否则导出表格里的时间戳会按美区计算。
6. 在编辑器顶部的函数下拉框选择 **`bootstrap`**，点 **运行**：
   - 首次会弹出授权 → 选择你的 Google 账号 → **高级 → 转至「一周日常表」（不安全）→ 允许**
     （脚本只申请 Google Sheets 权限，用于创建并读写你自己的表格）。
   - 执行日志会打印自动创建的表格链接。
   - 这一步可以跳过，首次打开网页时也会自动创建表格。
7. **部署 → 新建部署 → 选择类型：网络应用（Web app）**
   - 说明：`一周日常表`
   - **以谁的身份执行**：`我（你的邮箱）`
   - **谁可以访问**：`仅我自己`（想让同事一起填写就选 `组织内任何人` 或 `任何人`）
8. 点 **部署**，复制 **网络应用网址（Web app URL）**，在浏览器打开即可使用。

> 改了代码之后线上不会自动更新：需要 **部署 → 管理部署 → ✎ 编辑 → 版本选「新版本」→ 部署**。

## 使用

- 在任意一天的列上 **按住鼠标上下拖拽**（30 分钟一档）→ 填主题、与会人员、类别 → 保存，
  约 0.6 秒后自动写入 Google Sheet（页脚显示「已自动保存到 Google Sheet」）。
- 点标题可直接改标题；标题下方的日期跨度可改，表格列会跟着变。
- **显示时段** 默认 08:00–20:00，可切换 07:00–21:00 / 06:00–22:00 / 全天；打印内容与当前显示时段一致
  （Apps Script 的 iframe 里会另开一个只含当前视图的窗口再打印）。
- **导出到 Google Sheet**：在同一个表格里生成 / 刷新一张格式化的「日程表 Export」工作表 ——
  标题、日期范围、导出时间、品牌色表头、星期、时长、中英文类别、与会人员、合计行、冻结表头与筛选。
- 页脚的 **打开表格** 直达该 Google Sheet。

## 数据结构

自动创建的表格名为 **「一周日常表 · Weekly Schedule」**（在你的 Drive 根目录），含三个工作表：

- `Data` —— 每条日程一行：`id | date | start | end | title | category | attendees`
  （`start` / `end` 为从 00:00 起算的分钟数）
- `Meta` —— 界面设置：`title / start / end / lang / view`
- `日程表 Export` —— 导出成品表

想复用自己已有的表格：把该表格的 ID（网址里 `/d/` 与 `/edit` 之间那段）填到 `Code.gs` 顶部的
`SHEET_ID` 常量即可。

## 说明

- 样式沿用 Decathlon To-B 设计规范（品牌色 `#3643BA`、圆角 0、中性灰阶）。
- 直接用浏览器打开 `Index.html` 也能运行，此时自动退化为 localStorage 本地保存，导出按钮会提示仅在
  Apps Script 网页版中可用。
- 访问权限选「任何人」时，所有访问者读写同一个表格；如需按人隔离，请为每人单独部署一份。

## 已验证

- 前端 36 项（jsdom + 模拟 `google.script.run`）：云端载入 / 拖拽建日程 / 与会人员 / 自动保存 /
  导出按钮 / 中英切换 / 时段切换持久化 / 重开后恢复 / iframe 打印只含当前视图 / 无 Apps Script 时的本地退化。
- 后端 42 项（内存版 Sheets 模拟）：表格自动创建与清理、行写入与文本格式、日期被 Sheets 转成 Date 后的还原、
  状态往返、中英文导出表头与时长文案、排序、合计、冻结与筛选、重复导出不产生残留行、异常回传。

## 维护

`Index.html` 由 `build-index.py` 从网页版 `weekly-schedule.html` 自动改写生成（9 处断言式替换：
云端存储、防抖保存、iframe 打印窗口、导出按钮、表格链接、i18n 文案、启动流程）。
改动界面时请修改网页版后重新运行 `python3 build-index.py`，不要直接手改 `Index.html`，避免两边漂移。
